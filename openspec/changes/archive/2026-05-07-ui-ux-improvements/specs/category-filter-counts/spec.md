## ADDED Requirements

### Requirement: 分类筛选计数显示

系统 SHALL 在每个分类筛选按钮内显示该分类的样式数量。

#### Scenario: 筛选按钮显示计数

- **WHEN** 卡片数据加载完成
- **THEN** 每个分类按钮显示 `分类名 (n)` 格式，其中 n 为该分类的样式数量

#### Scenario: 全部分类计数

- **WHEN** 用户点击 "全部" 筛选按钮
- **THEN** "全部" 按钮显示所有样式的总数量

#### Scenario: 计数随筛选变化

- **WHEN** 用户选择某个分类后
- **THEN** 卡片网格仅显示该分类的样式，计数反映当前筛选结果

#### Scenario: 加载中状态

- **WHEN** 卡片数据正在加载
- **THEN** 筛选按钮显示 `分类名` (无数字)，表示加载中
